# Changelog

All notable changes to Unseen Changes Dot are recorded here.

## 1.0.29 - 2026-08-27

First public release candidate.

- Distinguishes new files from changed files with separate markers.
- Shows markers on files, parent folders, and background tabs.
- Stores state without adding frontmatter to notes.
- Reconciles seen state across synced vault configuration directories.
- Adds configurable colours, shapes, attachment tracking, and polling.
- Adds storage diagnostics and baseline reset commands.
- Documents privacy, storage, licensing, and release procedures.

## Earlier private builds

Versions 1.0.12 through 1.0.28 were private development builds. They were not
published in the Obsidian community plugin directory.
