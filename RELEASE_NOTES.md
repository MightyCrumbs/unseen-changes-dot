# Unseen Changes Dot 1.0.29

This is the first public release candidate of Unseen Changes Dot.

## Included

- Separate markers for new files and changed files.
- File explorer, parent folder, and background tab markers.
- Configurable states, colours, and shapes.
- Optional attachment tracking.
- Seen-state reconciliation for synced vault configuration directories.
- Storage status, debug, and baseline reset commands.
- No telemetry, analytics, or network requests.

## Compatibility

- Requires Obsidian 1.4.4 or newer.
- Do not enable Unread Dot and Unseen Changes Dot at the same time because both
  plugins add file-explorer markers.

See the README for storage, privacy, installation, and troubleshooting details.
